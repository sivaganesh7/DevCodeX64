# @DevCodeX64/api — NestJS Backend

NestJS + TypeScript backend API for the DevCodeX64 platform.

## Setup

\\\ash
pnpm install
pnpm dev
\\\

## Structure

- \src/config/\ — Configuration modules
- \src/common/\ — Guards, interceptors, filters, decorators, pipes
- \src/modules/\ — Feature modules (auth, users, repositories, etc.)
- \src/database/\ — Database module + Prisma service

## API Docs

Swagger UI available at \http://localhost:3001/api/docs\ when running.
